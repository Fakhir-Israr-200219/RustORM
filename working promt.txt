BIND VALUE STATUS
-----------------

Current BindValue:

    String(String)
    I64(i64)
    Boolean(bool)
    F64(f64)
    DateTime(chrono::NaiveDateTime)
    Decimal(rust_decimal::Decimal)
    Json(serde_json::Value)
    Null


PostgreSQL executor binding supports all
non-NULL BindValue variants.

NULL strategy:

    BindValue::Null
          ↓
    SQL literal NULL
          ↓
    PostgreSQL NULL
          ↓
    Option<T>::None


Important:

NULL is not bound as a SQLx parameter.

collect_bind_values() intentionally ignores
BindValue::Null because NULL should be expressed
through SQL NULL / IS NULL semantics rather than
a placeholder parameter.
